MULTI CLONE - ANDROID STUDIO PROJECT

BANANE KA TAREEQA
1. Android Studio kholein: File > Open > is "MultiClone" folder ko chunein (jis mein settings.gradle hai).
2. Gradle sync ka intezar karein (pehli baar internet chahiye, SDK 34 khud download ho jata hai).
   Agar Android Studio AGP/Gradle upgrade ka poochay to "Upgrade" ya "Remind me later" dono theek hain.
3. APK: Build > Build Bundle(s) / APK(s) > Build APK(s). Link "locate" par click karein.
   File: app/build/outputs/apk/debug/app-debug.apk
4. APK phone mein bhej kar install karein (Unknown sources ON).

PHONE PAR ISTEMAL
1. App kholein > neeche + dabayein > "Setup karein" > Android ki screen par Accept.
2. 1-2 minute baad dobara + dabayein > app chunein > tile ban jata hai, clone space mein copy install hoti hai.
3. Tile par tap: us app ki alag copy khulti hai (clone space mein). Pehli baar us mein naya login karna hoga.
4. Tile par long-press: Home Screen shortcut, Edit the name, Delete App, One Key Repair.

ZAROORI BAATEN
- Android 9 ya us se naya chahiye (minSdk 28).
- Ek app ki sirf ek clone copy ban sakti hai (work profile ki hadd). Alag alag apps ke jitne chahein clone.
- Kuch phones par company ne work profile band ki hoti hai; wahan setup nahi hoga.
- Clone space ki apps launcher mein briefcase ke nishan ke saath bhi nazar aa sakti hain.
